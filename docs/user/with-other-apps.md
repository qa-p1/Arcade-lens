# Works with other Arcade apps

Enable **Connect with other Arcade apps** in Lens’s Connected apps settings. You can turn off each peer separately. Lens keeps local capture and recognition available when it is used alone. An action appears only when its peer and the current platform support it.

| App | What Lens can do with it |
|---|---|
| Arcade Box | Run image presets or saved Box pipelines on a selection. |
| Arcade Clipboard | Send supported text, links, images, or files to your devices. KDE Connect can be a Linux fallback. |
| Arcade Look | Quick Look a selected path or supported file. |
| Arcade Shelf | Add a capture, recognized text, link, or file to Shelf. |
| Arcade Wheel | Add a selected action to Wheel. |
| Arcade Find | Search recognized text or a file path in Find. |
| Arcade Tools | Install, update, or remove Lens from Tools’ **Apps** tab. Tools can host the tray icon while Lens runs in the background. |

The expanded palette marks outbound actions with **↗** and shows exactly what they send. Lens removes outbound actions for content that appears to contain a password, key, or token.

Other apps can ask Lens to capture a region, analyze an image, recognize text and codes, or pin an image. Those actions can open Lens on screen; recognition can also run without opening the palette.

The Shelf and Find integrations were exercised with the real apps in an isolated runner. Windows and macOS were not run interactively on real desktops. See [Arcade Link details](../ARCADE_LINK.md) and [STATUS](../STATUS.md).
